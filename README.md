## 🚀 Overview

High-impact macroeconomic announcements (US Non-Farm Payrolls [NFP], Consumer Price Index [CPI], FOMC Interest Rate Decisions) cause massive multi-pip directional explosions. 

This engine pairs real-time economic calendar event countdowns with sub-millisecond price-delta detection, automatically placing directional breakout orders or post-spike mean-reversion trades with strict risk management.

---

## ✨ Features

- **Automated Economic Calendar Feed:** Ingests live schedules and high-impact filters (USD, EUR, GBP, JPY events).
- **Pre-News Countdown Guard:** Pauses standard OTC algorithmic bots 5 minutes before Tier-1 releases to prevent drawdown.
- **Microsecond Spike Capture:** Evaluates tick velocity in the first 300ms following release to confirm true breakout momentum.
- **Slippage Safeguard:** Discards orders if broker payout drops below configured floor (e.g., <80%) during high-volatility news windows.
